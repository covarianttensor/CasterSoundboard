Audio device management setup

If device management is unavailable, you can still play sounds using the Output selector in the main window. To manage devices and share microphone/soundboard audio here, CasterSoundboard needs:

  • pactl, the command-line tool used to control your desktop audio, with JSON support.
  • A running PulseAudio server, or PipeWire with its PulseAudio compatibility service (pipewire-pulse). PipeWire alone does not provide this connection.

The Diagnostics section below shows the actual failure. A connection error does not necessarily mean packages are missing.

1. Check what is missing

Run these in a terminal as your normal desktop user:

command -v pactl
pactl info
pactl --format=json list sinks

If pactl is not found, install the client tools. If it reports a connection error, check your desktop audio service using the distribution guide below. If JSON is unsupported, update the client tools and audio server using your distribution's packages.

2. Installation examples for Ubuntu and Debian

If only pactl is missing, install its tools package. This also works with an existing PipeWire desktop:

sudo apt update
sudo apt install pulseaudio-utils

If you are setting up a PipeWire audio desktop on Ubuntu 24.04 or newer, or Debian 12 or newer, the audio metapackage supplies the PulseAudio compatibility service and session manager:

sudo apt install pipewire-audio pulseaudio-utils

This can replace PulseAudio packages. Read your distribution's guide and review apt's proposed changes first. An already working PulseAudio desktop does not need to switch to PipeWire.

For a system intentionally using native PulseAudio instead, the alternative is:

sudo apt install pulseaudio pulseaudio-utils

Choose the setup appropriate to your distribution and desktop, then follow its activation or login/reboot instructions. These commands are examples for you to run; CasterSoundboard does not install software.

3. Distribution-maintained guides

  • Ubuntu: how desktop audio works
  • Debian: PipeWire installation and configuration
  • Fedora: troubleshooting sound problems
  • NixOS: PipeWire configuration and missing pactl

The apt examples do not apply to Fedora or NixOS. Follow their own package and service instructions. Installing CasterSoundboard with Nix on another distribution does not configure that distribution's audio service.

4. Try again

After pactl info and the JSON check succeed, click Refresh devices. The device controls will replace this guide, and the main-window Output selector will disappear.

If the commands work in your terminal but not here, the app may have a different PATH or be sandboxed (for example, Flatpak). Its package must include pactl and allow access to the desktop audio service; installing packages only on the host may not fix that. See Diagnostics below.
